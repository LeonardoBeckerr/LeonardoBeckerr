## Projetos em destaque

### ♻️ [Re.Source](https://github.com/ddsc-sts/re.source)

Plataforma B2B para anúncio, negociação e reaproveitamento de resíduos industriais.

O sistema possui cadastro e aprovação de empresas, anúncios, pesquisa por categorias, chat de negociação, propostas comerciais, entregas, confirmação por código, controle financeiro, solicitações de saque, estatísticas e painel administrativo.

No desenvolvimento colaborativo, participei do planejamento do MVP, da implementação e integração do fluxo principal, da estrutura do banco de dados, dos testes e da documentação do projeto.

**Tecnologias:** PHP, JavaScript, HTML, CSS, MySQL, Composer e PHPUnit.

---

### 💧 [AGUAPURA](https://github.com/ddsc-sts/AGUAPURA)

E-commerce acadêmico de garrafas, copos e acessórios reutilizáveis.

A aplicação conta com catálogo dinâmico, pesquisa, favoritos, carrinho, cupons, personalização de produtos, checkout, simulação de pagamento, histórico de pedidos e painéis para funcionários e administradores.

**Tecnologias:** Python, Flask, Jinja2, JavaScript, HTML, CSS e MySQL.

---

### 🍕 [Pizzaria Dalegé](https://github.com/ddsc-sts/Pizzaria-Dalege)

Sistema de cardápio digital desenvolvido para modernizar a experiência de atendimento em uma pizzaria.

Possui catálogo dinâmico, filtros por categoria, carrinho persistente, checkout, autenticação simulada e histórico de pedidos, com interface responsiva para desktop e dispositivos móveis.

**Tecnologias:** HTML, CSS, JavaScript, Local Storage e Session Storage.

---

### ⚖️ [Advocacia Voltolini](https://github.com/LeonardoBeckerr/Advocacia-Voltolini)

Site institucional responsivo para um escritório de advocacia, apresentando serviços, áreas de atuação e canais de contato.

O projeto utiliza animações de rolagem, navegação responsiva e páginas específicas para diferentes áreas jurídicas.

**Tecnologias:** HTML, CSS e JavaScript.
